# Project icons / images

Optional images for project cards. Referenced by the `icon` field in
`src/data/projects.ts` (e.g. `/projects/clone-app-profile.webp`).

- Recommended: square PNG, 128×128px or larger.
- If the file is missing, the card shows a clean letter-mark fallback.
- Adding a new project only requires one object in `projects.ts` plus (optionally)
  an image here — no component changes.
